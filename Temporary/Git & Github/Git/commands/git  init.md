get init command is used to turn a folder into a git repository

# Syntax

```Bash
git init [directory]
```

- to turn our current directory into a git repository, we simply need to run `git init` without specifying a directory. 
- But to created a new directory and turn it into a git repository, we need to specify the directory name.


# Notes

- just like all other git commands we need to run them **INSIDE** the directory we want to turn into a git repository. using the command `cd DirectoryPath`
