
-   **Git Basics**
    -   [[git  init]] - Initializes a new Git repository in the current directory.
    -   [[git status]] - Shows the status of changes as untracked, modified, or staged. 
    -   [[git add]] - Stages changes for the next commit.
    -   [[git commit]] - Records staged changes to the repository.
    -   [[git log]] - Displays the commit history.
    -   [[git reset]] - Undoes changes, moving the HEAD pointer and optionally modifying the staging area or working directory.
    -   [[gitignore]] - Specifies intentionally untracked files that Git should ignore.

-   **Branches**
    -   [[What is a branch]] - Explains the concept of a branch as an independent line of development.
    -   [[git branch]] - Lists, creates, or deletes branches.
    -   [[git checkout]] - Switches between branches or restores working tree files.
    -   [[git merge]] - Integrates changes from one branch into another.

-   **GitHub and Remote Repositories**
    -   [[creating a new  repository]] - Steps to set up a new repository, often on a platform like GitHub.
    -   [[git clone]] - Creates a local copy of a remote repository.
    -   [[git remote]] - Manages the set of tracked repositories.
    -   [[git fetch]] - Downloads objects and refs from another repository.
    -   [[git pull]] - Fetches from and integrates with another repository or a local branch.
    -   [[git push]] - Updates remote refs along with associated objects.
