# options

when creating a new repository we are met with the following menu

![[image-47.png]]

- we can select which account will be the owner of the repository **REQUIRED**
- we can choose the name of our repository **REQUIRED**
- we can write a description for our repository explaining what it is
- we can select whether we can make our repository open to the public to contribute to or private just for few members
- we can choose to add the README.md file which contains information about the repository, its purpose, and usage instructions, 
- we can choose to add a .[[gitignore]] file which specifies intentionally untracked files that Git should ignore, 
- we can choose to add a license, which is a crucial document that outlines the terms under which our project's source code can be used, modified, and distributed by others.
