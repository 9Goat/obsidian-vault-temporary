# Definitions

## What is a database?

- **French**: un ensemble structuré et organisé de données accessibles par l’ordinateur pour satisfaire simultanément plusieurs utilisateurs
- **English**: a structured and organized set of data accessible by the computer to satisfy simultaneously multiple users

## What is SGBD (Database management software)

- **French**:logiciel(s) qui permet d’interagir avec une BD.
- **English** :  software(s) that allows interaction with a database.

# Why use a SGBD

- Indépendance physique
- Indépendance logique
- Manipulation possible par des non informaticiens
- Accès efficace aux données
- Administration centralisé des données
	- security and data recovery tools
- Non-redondance des données
	- no repetition of data ,we can maintain the same data multiple times
- Cohérence des données (data consistency)
- Concurrence d'accès aux données
	- multiple users can access the same data in the same time 
- Sécurité des données
- Tolérer les pannes (problem recovery like power outage,crashes ,,,etc)

# Different types of DB

- Bases hiérarchiques
	-  a hierarchy structure using tree pointers
- Bases réseaux
	- fast data navigation using pointers
- Bases relationnelle
	- uses tables to store data and connect them using relationships
	- Bases déductives
		- uses logical orders and rules to derive new information from existing data.
	- Bases objet
		- just like objects from java

# Who is responsible for building databases

- Le concepteur de SGBD (The designer)
- L'administrateur de bases de données
	- responsible for creating the database and maintaining user access
- les développeurs et utilisateurs
	- responsible for using and manipulation the data
