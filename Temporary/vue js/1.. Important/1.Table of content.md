# Core Directives

Directives are fundamental attributes that extend HTML with special Vue.js functionality, used consistently across both API styles.

## 1. Text Directives

- [[v-text]] explains how to display text content and format variables within HTML elements. **Note: This directive will overwrite any existing text content of the element.**
- [[v-html]] is similar to [[v-text]] but allows you to render raw HTML content from a Vue.js variable, enabling dynamic HTML injection.

## 2. Binding Directives

- [[v-bind]] explains how to dynamically bind one or more attributes, or a component prop to a Vue.js expression, allowing attributes to react to data changes.
- [[v-model]] explains the concept of two-way data binding, demonstrating its use with form elements like text inputs to synchronize input values with component data.

## 3. Rendering Directives

- [[v-once]] allows an element or component to render only once, making it immune to future data updates and optimizing performance for static content.
- [[v-pre]] instructs Vue.js to skip compilation for the element and its children, displaying raw mustache tags and speeding up compilation for large blocks of static content.

## 4. Conditional Directives

- [[v-if statements]] explains how to conditionally render or destroy elements in the DOM based on a given expression, controlling their visibility.
- [[v-show]] is very similar to [[v-if statements]] but instead toggles the CSS `display` property of an element, keeping it in the DOM but hiding it.

## 5. loop Directives

- [[v-for]] directive is used to loo p through arrays or objects and render a list of items, allowing developers to easily create dynamic lists based on the data in their Vue components.

## 6. event directives

- [[v-on]] explains how to listen to DOM events and run some JavaScript code when the event is triggered, enabling interactivity within Vue.js applications.
