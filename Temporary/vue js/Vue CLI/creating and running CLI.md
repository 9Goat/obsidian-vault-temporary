to create a CLI vue project run the command

```bash
vue ui
```

this command will launch a gui that will allows us to create a project

# Important

for the project to be created successfully we MUST select npm as the package manager.

# Running the Project

Once the project is created, navigate to the project directory in the terminal. To start the development server, run the command 

```bash
cd ./project_location
npm run serve
```

this will allows us to create a virtual server to host our project
