To hide or show the layers panel, we use the hotkey **TAB**

![[image-223.png|600x200]]

there are 2 types of options in this image which are **ALL properties** which is the first option and it applies all the properties to the layers below it, and there is the **indvidual properties** which allows for specific properties to be applied to individual layers.

the following  properties are the following:

1. **Visibility**: you can either hide or show a layer
2. **Lock**: you can lock a layer from being modified (useful when we are done with a section and dont need to touch it)

**NOTE**: by **CTRL+CLICK** on any layer it  will select all the pixels in that layer


![[image-233.png]]


**Note**: to move a layer hover over the edge of the layer until it shows the move icon in which are can then move it either up be down
