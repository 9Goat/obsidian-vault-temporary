the grid is used to divide our drawing canva into blocks to help us make drawing easier

# Grid settings

to change the grid settings we go to view->grid->grid settings

![[image-230.png]]

with this setting we can  change the size and position of the grid

# viewing the grid

there are 2 types of grid that we can select which are the following:

- normal grid **CTRL+'**
- pixel grid **CTRL+ SHIFT + '** (this is fixed grid with position of 0 and size of 1 pixel)
