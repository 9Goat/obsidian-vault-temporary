# gradient bucket 

if we want to draw a gradient affect we use the gradient bucket with the hotkey of **SHIFT + G** which will create a gradient of our foreground and background colors.

![[2026-02-04_16-58-48.mp4]]

**Note**: for this and the [[selection tools#Magic wand|Magic wand selection tool]] we can set a tolerance number which indicates that it will similar colors as the same selected color
