there are many selection tools in asepriate that allows us to select a section of our  drawing and move it, copy it, or edit

- To exit a selection simply click the button **EXIT**
- by hovering over the edge of the selection tool we can also rotate our selection
	- if we want to our rotation to be symmetric we hold shift **WHILE** we are rotation not before

![[2026-02-05_16-39-19.mp4]]

# Lasoo tool

lasso tool allows us to draw a shape around the section we want to select. to access it we use the shortcut **Q**

![[2026-01-28_17-28-04.mp4]]

# Line  tool

this  tool allows us to select a line only ,we can use the tool with the  shortcut **SHIFT + Q**

![[2026-01-28_17-31-35.mp4]]

# Rectangle and circle tool

to select a section of our  drawing  in either  circle  or rectangle we can  use either of the following shortcuts:

- **FOR CIRCLE: SHIFT + M**
- **FOR RECTANGLE: M**

![[2026-01-28_17-33-41.mp4]]

# Magic wand

magic wand is basically  the fill bucket but used for selection  instead,to use the magic wand basically press the hotkey **W**


![[2026-02-02_17-14-21.mp4]]


# Selection properties

these  selection properties are very similar to figma:

![[image-229.png]]


1. **OR**: makes it so when  we select another area it deselects our previous  one
2. **AND / ADD**it selects both the  select area **This can also be achieved by holding shift while selecting**
3. **subtract** it  only selects the area that of the second selection that has no intersection with the first
4. **intersection**: it  selects the intersection  between both  selections
