Java is a language that uses classes and objects to execute code here is how it works


- you need an inner method that will act as the main code of our file ,for the java compiler to recognise it ,it has to be written word for word like this
	- **Example**: `public static void main (String args[])` except for args that word can be any name

# Code example

```Java
public class test{
public static void main(String a[]){
System.out.print("hello world!");
}
}
```
