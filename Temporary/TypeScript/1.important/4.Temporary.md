typescript has all the datatypes of javascript alongisde addiontal ones:

- any 

## Note

the type of the variable can be specificed be either:

- specificying its datatype with `let variableName :datatype`
- or by assigning a value to it `let variableName = "String"`
- it we dont do any of the both, the datatype of the variable will be **`any`** 
	- **example**: `let x;`


## Any datatype

as we said above if we dont explicitly specify the datatype of an object it automatically makes the datatype `any`, which defeats the entire purpose of typescript, which is datatype checking, the any datatype is the equivalent of saying:

 *i dont know the datatype of this variable, so whatever it is, try to work with it and hope  it does not cause an error*

## Array datatype

arrays do exist in java script, but they can contain any datatype, which may causes a problem for a function that expects an array to only contains number, the solution for this is to apply this syntax

```typescript
let x: number[] = []; //the datatype will be number[], not any[]
```

- this also works without explicitly specifying the datatype, just like regular variables if all the datatypes of the variables are the same inside an array the datatype of the array will match that

## tuples

tuples are basically arrays but with a limited size and unchangable order of datatypes on its elements

here is how to initialize a tuple

```typescript
let x: [string,number,boolean] = ["hello",3,true];
```

## enums

stands for enumeration, it allows us to create a variable that holds values with keys, similar to dictionaries , the only difference being that enums are fixed and cannot be changed (**read only**)

**Syntax**:

```typescript
enum enumName{
key1,
key2,
,,,,
keyN
}
```

- by default if we dont specify values of the keys, they will have an auto increment value starting from 0
- otherwise if we specify values there are 2 possible situations:
	- we specify numerical values, in that case the values of the keys after it will increment according to the specificed value

**Example**

```Typescript
enum Direction {  
Up ,  
Down,  
Left = -5,  
Right  
}  
  
console.log(Direction.Up); // 0  
console.log(Direction.Down); // 1  
console.log(Direction.Left); // 1  
console.log(Direction.Right); // 2
```

-  otherwise if we specify a non numerical value, we must specify the values of all the other keys *after it too*, until we hit a new numerical key specification otherwise it wont be valid code

**Example**

```typescript
//enum without constants  
  
enum Direction {  
Up ,  
Down,  
Left = "Left",  
Right = "Right",  
test = 1,  
test2  
}  
  
console.log(Direction.Up); // 0  
console.log(Direction.Down); // 1  
console.log(Direction.Left); // "Left"  
console.log(Direction.Right); // "Right"  
console.log(Direction.test); // 1  
console.log(Direction.test2); // 2
```


# functions

functions are exactly the same as javascript, except for specifying datatypes, here is what we should add to functions:

- **specify the datatype**: at the end of the parameters parenthesis we should add the datatype
- **specify the parameters datatype**: after the name of each parameter we should specify the parameter datatype
- **Example of both**:

```typescript
let x :number[] = [1, 2, 3];

function printArray(arr: number[]) : number[] {
console.log(arr);
return arr;
}

printArray(x);
```
