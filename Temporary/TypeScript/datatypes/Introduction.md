# Difference between javascript and typescript

## Dynamic and static typing

- **static**: when we declare a variable we have to specify its datatype, so that it can only accept its type of data when assigning values and also so methods can expect a specific datatype from a variable
- **dynamic**: you dont have to specify the datatype of a variable, the datatype of the variable changes depending on the value we assign it with, this results in error that occur after we run our code, for example we put a number variable inside a method that accepts string, we couldnt know in that moment because the variable datatype can change through out the project
