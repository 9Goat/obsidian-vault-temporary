# modes
![[image-90.png]]
in figma there are 3 main modes which are:

- draw
- design
- dev

## Draw mode

![[image-91.png]]

in the draw mode we get the following tools:

- cursor options
- pen
	- with pen we can create custom shapes by connection dots and lines
- brush
- pencil
- frame options
- shapes options
- text
- comments
- actions section

![[image-92.png]]

## Design Mode

in the draw mode we get the following tools:

- cursor options
- frame options
- shapes options
- drawing options
- text
- comments
- actions section

### Cursor options

![[image-93.png]]

- cursor is the option we are going to selecting 99% of the time  it does everything else that other tools cursor tools can do.

- hand tool it allows to move around without moving other elements by accident (you can quickly switch to it while in cursor mode by holding the scroll wheel or space bar)

- scale allows to to scale objects X and Y axes **EQUALLY** (you can do the same in the cursor mode by holding shift while scaling)

![[2025-11-21_13-52-56.mp4]]

### Frame options

![[image-94.png]]

- frame tool is create pages in 2 types of shapes:
	- select from a predefined list of device frames
	- ![[image-95.png]]
	- or draw your own shape just like the rectangle shape tool

- sections are used as containers for pages they are used to divide our works into section

- slice allows you to export sections of your design as a separate image or asset,
