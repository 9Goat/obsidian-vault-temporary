# JSX

the first notable thing that i learned about react is the jsx syntax, a way to create a component in react is to write a function like this

```javascript
function MainContent() {  
return (
<h1>React is great!</h1>
)
}  
  
root.render(  
<div>  
<MyAwesomeNavbar />  
<MainContent />  
</div>  
)

// Note: components are not required to be self closed when calling the, sometimes we can put other elements inside of it
root.render(
<Page>Placing some elements inside</Page>
)
```

- the main function is the component where it returns jfx syntax elements, if there are multiple elements we write the return as `return (//multiple elements here)`
- and to render it we use the render element
- **Note**: render function only accepts a single root element inside it, meaning if we want to include multiple elements inside of render we have to surround them inside a single root element like div in this example
- the parameters are mainly for  decoration they are not required

## How to get the render element

first we mark an element inside our `index.html` file with an id that we are going to call later in js

```html
<body>  
<div id="root"></div>  
<script src="/index.jsx" type="module"></script>  
</body>
```

and in js we have to import a function from react and attach to it that element using getElementById

```js
import { createRoot } from "react-dom/client"

const root = createRoot(document.getElementById("root"))
```

## Fragment

instead of surrounding the code inside of a div element, *since we have to put  in a single root element*, we instead can use the built it `Fragment` component from react, the benefits of this is that we dont end up with a nested div, which may causes some problems especially with css styling if we have a global css styling for div elements

```jsx
import { createRoot } from "react-dom/client"  
import { Fragment } from "react"  
  
const root = createRoot(document.getElementById("root"))  
  
function Page() {  
return (  
<Fragment>  
<header>  
<img src="react-logo.png" width="40px" alt="React logo" />  
</header>  
<main>  
<h1>Reason I am excited to learn React</h1>  
<ol>  
<li>React is a popular library, so I will be able to fit in with all the coolest devs out there! 😎</li>  
<li>I am more likely to get a job as a front end developer if I know React</li>  
</ol>  
</main>  
<footer>  
<small>© 2024 Ziroll development. All rights reserved.</small>  
</footer>  
</Fragment>  
)  
}  
  
root.render(  
<Page />  
)
```

## Nesting components

to create a folder structure where different components are placed within separate file, we have to export them for them to be visible to other components when we want to use them to do that we add **`export default`** before the file name and then import them when we need them

```jsx
export default function Footer(){  
return (  
<footer>  
<small>© 2024 Ziroll development. All rights reserved.</small>  
</footer>  
)  
}
```

## using javascript inside of jsx

outside the html elements we can use simple javascript expressions, we are already familiar with that, but the challenge becomes clear when we want to write javascript expressions inside of the html elements, for example like the text inside a h1 element, to make any javascript express valid inside of html we simple have to surround them with a single curly bracket

```jsx
function App() {  
const firstName = "Joe"  
const lastName = "Schmoe"  
  
return (  
<h1>Hello {firstName} {lastName}</h1>  
)  
}
```

- this will write: `Hello Joe Schmoe`
# Styling

jsx styling is not so different than regular HTML in terms of syntax structure

## ClassName

instead of using the html property `class` instead in jsx we use **`className`** so that we can style it inside of a css file

### exporting

```jsx
function Header() {  
return (  
<header className="header-component">  
<img src="/src/assets/react-logo.png" className="header-logo" alt="React logo" />  
<nav>  
<ul className="nav-list">  
<li>Pricing</li>  
<li>About</li>  
<li>Contact</li>  
</ul>  
</nav>  
</header>  
)  
}
```

- we apply these static class names directly on our JSX elements, and then define the corresponding CSS rules in a separate `.css` file

### Importing them

```jsx
import Header from "./Header";  
import Footer from "./Footer";  
import Main from "./Main";  
  
export default function Page() {  
return (  
<>  
<Header />  
<Main/>  
<Footer></Footer>  
  
</>  
)  
}
```

## Receiving the parameter

the parameters get sent to that component under one single object, for example here we sent an object with parameters so when we run this code:

```jsx
export default function Contact(whatever) {
console.log(whatever)
return(<h1>Hello world</h1>)
}
```

we get this result from the console log message:

```js

{img: './images/fluffykins.png', name: 'Fluffykins', phone: '(212) 555-2345', email: 'fluff@me.com'}
```

### Destructing props

to destruct a prop we need to first learn how to destruct  a javascript object, to do that we need to declare the variable in curly brackets `{variable1,variable2}` and assign the object to them, when naming the variables inside the curly brackets we have 2 options:

1. naming them as the same name of the attributes inside the object
2. use this simple trick `{variable1:alias1,variable2:alias2}` in this case the name of the variable must match the name of the attributes inside the object, but we can use the alias as the variable holding the value of the attribute

**Example**

```js
const person = {  
img: "./images/mr-whiskerson.png",  
name: "Mr. Whiskerson",  
phone: "(800) 555-1234",  
email: "mr.whiskaz@catnap.meow"  
}

const {img, name} = person
console.log(img + name)

//OR

const {img: image, name:fullName} = person
console.log(image+fullName)
```


we can use that principal to destruct the props object and get it as separate variables, and use those variables inside our html elements without having to mention the props name

**Example**

```jsx
export default function Contact({img, name, phone, email}) {  
return (  
<article className="contact-card">  
<img  
src={img}  
alt="Photo of Mr. Whiskerson"  
/>  
<h3>{name}</h3>  
<div className="info-group">  
<img  
src="./images/phone-icon.png"  
alt="phone icon"  
/>  
<p>{phone}</p>  
</div>  
<div className="info-group">  
<img  
src="./images/mail-icon.png"  
alt="mail icon"  
/>  
<p>{email}</p>  
</div>  
</article>  
)  
}
```

- **Note**: there is no benefit to doing this, it is just up to the preference of the project maintainer
- if we dont a parameter, it will contain the value of **`undefined`** inside the props object

- **valueName = {value}**: works with every datatype including string

- **Note** the problem with this code is that we repeat the word entry alot, one way to remove that is to pass the entry object like this

```jsx
import Header from "./components/Header"  
import Entry from "./components/Entry"  
import data from "./data"  
  
export default function App() {  
  
const entryElements = data.map((entry) => {  
return (  
<Entry  
key={entry.id}  
{...entry}  
/>  
)  
})  
  
return (  
<>  
<Header />  
<main className="container">  
{entryElements}  
</main>  
</>  
)  
}
```

- the 3 dots before the object name, destructs the object resulting in passing all the variables without an object

# Static images

when working with static images, especially when Storing images in the `src/` folder like **`'./assets/hero.jpg'`** there is a chance that the image will not work due to how vite compresses those files, to fix that we need to import them

```jsx
import heroImage from './assets/hero.jpg'; // Import required here  
  
function Hero() {

);  
}
```

# How to reuse react components with map function

to create multiple copies of the same component but  passing multiple  props with different data to get different componet we need to do 3 things which are:

1. creating a data object, preferably in a file or just fetching them from db
2. creating a component to accept the props
3. passing the props using the map function

## Example

### Object file

```js
export default [  
{
id:1,
setup: "I got my daughter a fridge for her birthday.",  
punchline: "I can't wait to see her face light up when she opens it."  
},  
{
id:2,
setup: "How did the hacker escape the police?",  
punchline: "He just ransomware!"  
},  
{
id:3,
setup: "Why don't pirates travel on mountain roads?",  
punchline: "Scurvy."  
},  
{
id:4,
setup: "Why do bees stay in the hive in the winter?",  
punchline: "Swarm."  
},  
{
id:5,
setup: "What's the best thing about Switzerland?",  
punchline: "I don't know, but the flag is a big plus!"  
}  
]
```


### creating the component

```jsx
export default function Joke(props) {  
return (  
<>  
{props.setup && <p className="setup">Setup: {props.setup}</p>}  
<p className="punchline">Punchline: {props.punchline}</p>  
<hr />  
</>  
)  
}
```

### passing them using map function

```jsx
import Joke from "./Joke"  
import jokesData from "./jokesData"  
  
export default function App() {  
const jokeElements = jokesData.map((joke) => {  
return <Joke 
key={joke.id} // VERY IMPORTANT
setup={joke.setup}
 punchline={joke.punchline} 
 />  
})  
return (  
<main>  
{jokeElements}  
</main>  
)  
}
```

- when creating an array of elements we should always assign a prop called **`key`** with a **UNIQUE** value so that when we are dealing with either editing or deleting one of those elements from the list, react can know which react we are referring to
