PHP is a programming language used for web development, especially for back end development it allows developers to connect their web pages with a server and database,

# Syntax

you need a web server *like apache* to run your code.Once you have it create a php file

```Php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
 <h1>this is a normal text</h1>
 <?php
echo "this is my first code"
 ?>
</body>
</html>
```

- php file is simple an HTML file but it contains PHP code embedded within
- to embed PHP code within HTML, you surround it with
	- **`<?php //code here ?>
