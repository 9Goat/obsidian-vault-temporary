used as an alternative for type casting in php

# Syntax

```Php
booleanResult = settype(variable ,"dataType"); //return true of false depending on the success of the operation.

// same as typecasting (the only difference is it modifies the original variable)

returnVariable = (dataType)$variable;
```

the datatypes allowed inside of php are:

- **"boolean" or "bool"**:Converts the value to a Boolean (true or false).
- **"integer" or "int"**:	Converts the value to an Integer (whole number).
- **"float" or "double"**:Converts the value to a Floating-point number (decimal).
- **"string"**:	Converts the value to a String.
- **"array"**:	Converts the value into an Array.
- **"object"**:	Converts the value into an Object.
- **"null"** :Converts the variable to NULL.
