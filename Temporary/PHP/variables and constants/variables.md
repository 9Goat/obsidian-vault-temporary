to declare variables inside of php you need to use the dollar sign ($) followed by the variable name.

# Syntax

```Php
<?php
$variableName = value; //intialization

$variableName; //declaration
?>
```

# Notes

just like other programming languages there are certain rules on how you can name a variable:

- the first character **MUST** be either a letter or underscore `_` *it cannot be a number*.* 
- other than that you can use any combination of characters
