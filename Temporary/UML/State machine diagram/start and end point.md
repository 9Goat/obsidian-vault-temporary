in state machine diagram there is a single starting point and multiple ending point:

the **Initial State** is not actually a true "state" where an object sits and waits. Instead, it is a **pseudo-state**—a starting marker.

the **Final State** represents the finish line. It means the state machine (or a specific sub-state) has successfully completed its execution. DET may have multiple of none of a final state (example of a loop DET)
