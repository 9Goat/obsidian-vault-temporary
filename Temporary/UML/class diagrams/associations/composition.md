composition is extremely similar to [[aggregation]] except that it requires 2 addtional things to be considered a composition instead of [[aggregation]] which are:

- it the parent class gets deleted the child classes (classes connected to it) get deleted as well
- the child class can only exists a single time which is inside the parent class meaning its association with the parent class has 1 multiplicity to it (we dont write it since its always a 1)
