
# Basics

the actors involved in the use case are connected to it using an **Association**

>[!info] Association
>we call an association a link between any entity in a diagram not only to actors and uses cases that is mostly showcased with different types of arrows depending on the type of the connection

# Types of association

there are 3 main types of associations which are:

- **Arrow to Use Case** (Actor→Use Case)
- **Arrow to Actor** (Use Case→Actor)
- **Straight Line** (Actor−Use Case)

## Arrow to use case

**The Actor started it.** (Actor is the _Primary Initiator_ and the use case is *secondary*). and the use case is used to execute a functionality and wont display an information back to the user

![[image-31.png]]

## Arrow to Actor

**The Use Case started it.** (The system is the _Primary Initiator_). and the use case will return a result/data back to the actor withing have the actor to start it

![[image-30.png]]

## **Straight Line**

Actor started it BUT the use case returns data/information.
