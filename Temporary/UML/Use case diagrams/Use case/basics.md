# Definition

- **French:**
	- C’est un service rendu à l'utilisateur, il implique des séries d'actions plus élémentaires. (résultat observable pour un acteur).
	- Un cas d'utilisation est l'expression d'un service réalisé de bout en bout , avec un déclenchement, un déroulement et une fin, pour l'acteur qui l'initie.
- **English**:
	- It is a service provided to the user, it involves a series of more elementary actions (observable result for an actor)
	- A use case is the expression of a service carried out from end to end, with a trigger, a progress and an end, for the actor who initiates it

A **use case** is a **functionality or goal** that the system provides to the actor. Think of it as an action the user wants to perform.

# How to create a usecase

simply draw a horizontal circle that contains the title of the use case,which is written like this:
- verbe a l'infinitif + complément
- **Examples**: 
	- PasserCommande
	- Ajouter article
	- Suivre commande
