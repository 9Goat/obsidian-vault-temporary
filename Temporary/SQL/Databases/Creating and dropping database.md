
# Creating a database
## Syntax

```SQL
CREATE DATABASE database_name;
```

- this command is best paired with [[Using a database]] to immediately start working with it

## Example

```SQL
CREATE DATABASE database_example;
```

# Dropping a database

## Syntax

```SQL
DROP DATABASE database_name;
```

- this command is best paired with [[Selecting current database]] to see which database is being worked on after executing the command.

## Example

```SQL
DROP DATABASE database_example;
```
