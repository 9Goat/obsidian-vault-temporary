# Important things about SQL

the overall  idea of SQL is still the same between all DBMS (DataBase Management Systems) but the syntax behind it may change which makes switching  between  one DBMS to another extremely useful,there are 4 main DBMS to keep in mind:

- ORACLE
- MySQL
- Microsoft SQL
- PostgreSQL

## Notes

- while some DBMS allows us to omit ending a statement with semi colon **`;`** it is still best practice to end each  statement of sql with it
- it is best practice to write keywords in full caps like **`SELECT`** while naming everything else like tables and columns using snake case **`first_name`**
