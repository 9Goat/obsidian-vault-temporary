## Constraints

do research on all types of constraint

### column constraints

- create table_name ( column_name datatype column_constraint,)
	- **For example**: create table test (id int unique)

### table constraint

one way we can set our table constraint is by using alter table

- alter table table_name add constraint constraint_name table_constraint (columns_name);
	- **For example**: alter table test add constraint unique_id unique (id);
- OR if we want to create a constraint without a name we do this
- alter table table_name add table_constraint (columns_name);
	- **For example**: alter table test add unique(id);

an another way to do this is by specificying it at the end of creating a table

- create table table_name (column_name1 datatype, column_name2 datatype, constraint constraint_name constraint (columns)

**OR** create it without name like this

```SQL
CREATE TABLE project_deadlines (
    start_date DATE,
    end_date DATE,
    CHECK (end_date > start_date) -- No name given
);
```

- alter table table_name drop constraint constraint_name;
	- used to drop a constraint by the name of the constraint

- alter table table_name auto_increment = number;
	- used to set the starting counting number for the auto increment value (**NOTE**: it is best practice to make sure the column containing it is **UNIQUE**)

# select

- select [column1,column2, column3] or * from table_name where condition;
- select DISTINCT column1, column2 FROM table_name WHERE condition;
	- DISTINCTCT means we do no allow duplicates
- select DISTINCT column1, column2 FROM table_name WHERE column like "pattern"
	- the pattern in the like clause can include % for many and _ for a single character
	- also instead of like we also can use REGEXP and use regex expression instead of the like express to describe a pattern we want to find
- inner join,left join and right join
	- **NOTE**: a self join is when a table is joined with itself
- instead of using the on followed by the condition like this
	- **Example**: select * from table1 as t1 on table2 as t2 on t1.column = t2.column
	- we can replace it by the keyword using following by the name of the column inside of parentheses
	- **Example** select * from table1 on table2 using (column) //which is basically the same statement as the above
- select columns from table1 natural join table2
	- this the equivalence of writing a simple inner join statement where we put all the columns that have the same name inside of using for the sake of simplicity
- select columns from table1 cross join table2
	- this syntax is used when you want to combine each row of one table with each row of another table, resulting in a Cartesian product of the two tables, where the number of rows in the result is the product of the number of rows in each table. for example 10 * 10 = 100
	- the short version of this syntax is to replace the cross join keyword by a simple comma (,). So instead of writing `select columns from table1 cross join table2`, you can simply write `select columns from table1, table2`.

# procedure

procedure is used to save sql statements that we use often to save time

```SQL
DELIMITER $$
CREATE PROCEDURE function_name()
BEGIN
//SQL STATMENT HERE for example SELECT * FROM Customers;
END $$
DELIMITER ;
```

- without the delimiter chance the program will end the statement at the semi colone **;** set at the end of the sql statement of select  instead of end which is why we temporarily chance the  delimiter
- and the execute the  producer that we have  saved we use
	- **CALL function_name();**
- and to drop a procedure we use the following statement
	- **DROP PROCEDURE function_name;**

# copying a table

to copy a table use this syntax

```SQL
create table_name as select * from original_table;
```

but keep in mind this will copy all the inserted data and structure except for the following:

- **Indexes:** You will have to recreate them manually.
- **Primary Keys:** The new table won't know which column was the PK.
- **Auto-Increment:** The new ID column will just be a normal integer.
- **Constraints:** Foreign keys and check constraints are typically not copied.
