# Things to avoid

## Doubles

in pixel art doubles are excessive pixels that appear at the corners of a curve,these doubles make those curves appear more sharp and make them loser their smoothness.

![[image-243.png]]
![[image-247.png]]
## Jaggies

normally when we want to draw a smooth curve we have to follow a certain pattern,but if we dont we end up with something called jaggies which are pixels that are not aligned properly

![[image-244.png]]
![[image-248.png]]

# Concepts to follow

## Perfect angles

if we want to draw a perfect line we just have to decide a certain number of pixels to be used for a certain angle,

![[image-245.png]]

## Joining angles

when we want to connect 2 angles we have 2 options :

- make the joining angle appear sharp by using few pixels
- make the joining angle appear smooth and flat by using more pixels

![[image-246.png]]

# Conclusion

if we want to draw smooth curves and lines we have to follow a certain repeating pattern.
