# Navigation

- **`CTRL + UP OR DOWN`** instead of manually using our cursor to navigate code, instead we can use this command
- **`CTRL + P`** this short cut opens a search bar that allows us to do the following
	- search through files by simply typing the name of the file
	- **@object/variable**: to search through variables, objects , methods or basically any symbol inside of your project just write its name after the at symbol
	- **#object/variable** the same thing as above, but instead of searching through only the symbols inside a specific file, this command allows us to search through the entire project
	- **:line number**: when we want to go to specific line we dont have to scroll through it, instead we can just write the line number after the points
- **`CTRL + D`**: this shortcut have 2 main functionalities which are the followings:
	- when we run into a variable or object or any symbol name and we want to select it, we can use this command instead of shift + CTRL + arrow key
	- when using this shortcut on a selected variable or object it selected **ALL** of its occurrences which allows us to edit all of them
- **`ALT + CLICK`**: on multiple places allows us to modify the text of multiple places, such as adding text, or deleting text
- **`CTRL + X`** at the end of the line to complete delete a line and copy it into our clipboard
- **`CTRL + SHIFT + K`** similar to the above except that it does NOT copy to our clipboard
- **`ALT + UP OR DOWN`** to move a full line or selected text into an another location either up or down
- **`ALT + SHIFT + UP OR DOWN`** same as below but except of just moving, we are duplicating the code, its basically the equivalent of copy and pasting the code  at every up or down arrow
- **`CTRL + L`**: highlights an entire line 
- **`CTRL + /`** comments an entire line of all selected text
- **CTRL + \`  **:** open and closes the terminal
- **`CTRL + ALT + N`** to run code
