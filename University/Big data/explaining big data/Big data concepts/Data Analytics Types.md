# Introduction

Data analytics is the process of examining data to extract insights and support decision-making. There are **four main types** of analytics, each answering a different question and providing a different level of insight.

| Type             | Question It Answers        | Difficulty                          | Value            |
| ---------------- | -------------------------- | ----------------------------------- | ---------------- |
| **Descriptive**  | What happened?             | ⭐ Low                               | 📊 Reporting     |
| **Diagnostic**   | Why did it happen?         | ⭐⭐ Medium                           | 🔍 Investigation |
| **Predictive**   | What will happen?          | ⭐⭐⭐ High## **Diagnostic Analytics** | 🔮 Forecasting   |
| **Prescriptive** | How can we make it happen? | ⭐⭐⭐⭐ Very High                      | 🎯 Optimization  |


# 1. Descriptive Analytics

## Definition

**Descriptive analytics examines historical data to understand what has happened in the past.**

## Key Characteristics

- 📊 **Looks backward** at historical data
- 📈 **Summarizes** past events
- 📋 **Reports** on what occurred
- 🔢 Uses **basic statistics** (counts, averages, percentages)

# 2. Diagnostic Analytics

## Definition

**Diagnostic analytics digs deeper into data to understand the causes and reasons behind past events.**

## Key Characteristics

- 🔍 **Investigates** root causes
- 🧩 **Finds relationships** between variables
- 📊 **Drills down** into data
- 🔗 **Correlates** different data sources

# 3. Predictive Analytics

## Definition

**Predictive analytics uses historical data, statistical models, and machine learning to forecast future outcomes.**

## Key Characteristics

- 🔮 **Looks forward** to the future
- 📊 **Uses probability** and statistical models
- 🤖 **Employs machine learning** algorithms
- ⚠️ **Provides estimates**, not certainties
- 📈 **Identifies trends** and patterns

# 4. Prescriptive Analytics

## Definition

**Prescriptive analytics recommends specific actions to achieve desired outcomes or optimize decisions.**

### Key Characteristics

- 🎯 **Provides recommendations**
- ⚖️ **Evaluates trade-offs**
- 🚀 **Optimizes** decisions
- 💡 **Suggests actions** to take
- 🔄 **Continuously learns** and improves

# Summary

```text
Value
  ↑
  │                                    🎯 Prescriptive
  │                                   "What should we do?"
  │                                          ↑
  │                                   🔮 Predictive
  │                              "What will happen?"
  │                                     ↑
  │                              🔍 Diagnostic
  │                         "Why did it happen?"
  │                                ↑
  │                        📊 Descriptive
  │                   "What happened?"
  │
  └──────────────────────────────────────────→ Difficulty
```

|Aspect|Descriptive|Diagnostic|Predictive|Prescriptive|
|---|---|---|---|---|
|**Time Focus**|Past|Past|Future|Future|
|**Question**|What?|Why?|What will?|How to?|
|**Data Needed**|Historical|Historical + Context|Historical + Patterns|All + Constraints|
|**Techniques**|Reporting, Stats|Data Mining, Correlation|ML, Statistics|Optimization, AI|
|**Output**|Reports|Insights|Forecasts|Recommendations|
|**Example Tool**|Excel, Tableau|SQL, BI tools|Python, R, ML|Advanced AI systems|
|**Business Value**|Low|Medium|High|Very High|
|**Difficulty**|Easy|Moderate|Hard|Very Hard|

## Example

|Industry|Descriptive|Diagnostic|Predictive|Prescriptive|
|---|---|---|---|---|
|**Retail**|Sales reports|Why products don't sell|Demand forecasting|Pricing optimization|
|**Healthcare**|Patient history|Disease cause analysis|Disease risk prediction|Treatment recommendations|
|**Banking**|Transaction reports|Fraud pattern analysis|Credit risk scoring|Investment strategies|
|**Manufacturing**|Production reports|Defect root cause|Equipment failure prediction|Maintenance scheduling|
|**Marketing**|Campaign performance|Why campaign failed|Customer behavior prediction|Ad spend optimization|
