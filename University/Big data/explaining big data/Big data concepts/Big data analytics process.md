- Generating data
- storing data 
- processing data 
- Generating insights and predictions

# 1. Generating data

since in big data we record every instance of the data we end with the following:

Data generation from various sources every click, every transaction, every sensor reading.

# 2. Storing data

data is stored inside a disturbed system that supports big data, such as hadoop

# 3. Processing the data

**Data is analyzed, transformed, and processed** to extract meaningful patterns and insights.

# 4. Actionable insights

the result from processing the data provides us with predictions and patterns that we can  use for business knowledge to make decissions
