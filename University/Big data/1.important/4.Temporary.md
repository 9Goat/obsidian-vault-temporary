1. definition of big data:
	1. very large dataset
	2. complex, made of many types of data
	3. cant be analyzed with usual tools like databases
2. 5 vs of big data
	1. values: large data, reduction in storage costs, no data is useless store everything
	2. velocity: the speed in which data gets generated and  processed it
	3. variety: different types of data(structured unstructured and semi structured) come from different types of sources
	4. veracity: the quality and trust worthiness of the data
	5. value: usefulness the data provides with its insights
3. types of data
	1. structured: databases
	2. unstructured: distributed system
	3. semi structured: has structure but not like a table (json for example )
4. traditional approach
	1. defines business needs: we need to solve a problem
	2. design a solution (database schema or tables)
	3. gather the data 
	4. store it in database
	5. generate a report using queries
5. big data approach
	1. identify all sources of data
	2. store everything
	3. explore and discover
	4. ask questions after exploring data patterns
	5. repeat
