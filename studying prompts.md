# Searching for resources


```markdown
I want to learn [TOPIC] and need you to find the best learning resources for me.

About me:
- Background: [what you already know, e.g. "experienced with Vue and Angular, so skip general frontend fundamentals"]
- Goal: [what you want to be able to do, e.g. "build production-level apps and pass interviews"]
- Preferences: [e.g. "free resources preferred", "English only", "hands-on over theory"]

Task:
Search the web for resources and organize them by type: videos/courses, books, websites/documentation/articles, GitHub repositories, and (if relevant) interactive practice or communities.

Requirements:
- Give 3 to 5 resources per category, prioritizing quality over quantity.
- Every resource must be well structured, with a clear progression through the concepts.
- Skip beginner basics I already know, and highlight what's different from what I know.
- Prefer resources that are current (published or updated in the last 2 years) and note the date or version when relevant.
- Only include resources you actually found in your search, with a working link. Do not invent titles or URLs.

For each resource, include:
1. Title and link
2. Creator/author, and whether it's free or paid
3. Level and approximate time commitment
4. One or two sentences on why it fits my background and goal

At the end, suggest a short recommended learning order using the best resources from the list.
```
