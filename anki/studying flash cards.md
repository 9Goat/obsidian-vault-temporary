## Tagging

You can create tags related to certain flash cards to help group them and create custom study around them
![[Pasted image 20241116183546.png]]

#### Sub Tags

you can create tags in folder like structure by using this syntax:

`main_tab::sub_tag1::sub_tag2_of_tag1::sub_tag3_of_tag2,,,etc`

#### colorful tags

we use colorful tags to differentiate between tags.A good use of tags is to give each color a meaning for example all math related tags will be blue

**How to use it**:
 right click on the tag you want to apply the color to and simply click **'assign color'**
