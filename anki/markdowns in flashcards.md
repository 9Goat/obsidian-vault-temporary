Akin offers a variety of ways to add markdown to flashcards by interacting with this section when create a card ![[Pasted image 20241113045810.png|lp right]]

1. **Bold (ctrl+b)**: bold lets you use **bold** test obv. you can select text and activate it to turn it into bold or write new text and that will also be bold.
2. **Italic (ctrl+i)**: the same as bold but with italic text instead.
3. **underline (ctrl+u)**: the same as above but makes the text underlined instead.
4. **superscript (ctrl+=)**: makes text smaller and half a character above normal text. Great for creating simple equations.
5. **subscript (ctrl+shift+=)**: the same as subscript but instead half a character below normal text.
6. **text color**: by pressing the text color button you are changing the color of the text selected or the text you are typing after pressing
	- **NOTE**: You can change the text color option by clicking the down arrow icon next to it and you will be presented with a color option
7. **text highlight**:Same thing as color text but changes the background color of the text instead
	- **NOTE:** you can also change the color the same way you would with text color.
8. **format clear(ctrl+r)**:removes all formatting effects selected or removes all formatting text *applied* to selected text
9. **unordered list (ctrl+,)**: lets you create an unordered list
10. **ordered list(ctrl+.)**:lets you create an ordered list
11. **text alignment adjustment**: there are a couple of options listed ![[Pasted image 20241113053244.png]]
	1. normal text:
	- **right**
	- **center**
	- **left**
	- **justify**
	2. lists:
	- **indent(ctrl+shift+.)**: used to nest lists by indenting a list inside a list
	- **decrease indent(ctrl+shift+,)**: decrease the indent of a list to manage list alignment / nesting
12. **attach media (pic/vid/mp3):** you can attach media to you flash cards by clicking on the media button and selecting a file from your computer.
	1. **images(currently works on images only):** after inserting your image you can control its float by clicking on it and choosing the float type (left,right or none). You can also change the size of the image.To delete the image just click on it and press the delete key.![[Pasted image 20241113054433.png|lp right]]
13. **add equations:** choose one of the supported type of equations and write your equation the in supported syntax inside the opening (exp [LATEX]) and closing (exp [/LATEX]) tags![[Pasted image 20241113054741.png|lp right]]
