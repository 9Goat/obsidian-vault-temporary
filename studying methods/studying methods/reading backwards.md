a great way to learn from resources and save time is to try to understand it before reading it:

1. always refer to the simplest and most reliable summaries (for example a summary page in the resource) and read them first
2. scan the resource with your eyes quickly and try to get as many information as possible (for example looking for graphs)
3. after that if we get whats the main idea of our resource is we can start to fully read it ,if not repeat the process

**important to consider**:

- its always better to know what you do know and dont about a topic . *but how?*
	- by finding/creating using AI questions to test our knowledge we can see what we possible can be tested about when doing an exam for a certain topic
	- after we are done learning from the resources we should go back and try to answer the questions if we fail that means we have not understood enough
