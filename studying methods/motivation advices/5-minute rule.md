The 5 minute rule is a technique that helps us get productive and actually do the work here is how it works:

- convince yourself that you will be only doing a certain tasks for **only 5 minutes**
- after we are done with the 5 minute work we can leave at any time but we wont, why?
	- the hardest part about doing a task is actually starting it not doing it
	- we use this technique to trick ourselves into starting a task by downplaying into *5 minute work only!!**
- another helpful thing to consider is breaking tasks into smaller, manageable chunks. When faced with a large task, it's easy to feel overwhelmed and put it off. By breaking it down into smaller tasks, you can apply the 5-minute rule more effectively and make the task feel easier and more manageable which helps us convince ourselves to start working on it.
